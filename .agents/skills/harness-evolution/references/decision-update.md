# 观察与结论

仅在用户要求保存本轮研究观察或结论时使用，沿用实际业务 Agent、来源与 Run；查询任务直接报告，不为保存结论重新执行评测。

1. 在所属业务目录的已有设计或研究说明中保存假设、实际比较、Run 引用、反例、回归、限制和下一步。没有适合位置时只创建本次确需的说明文件，不另建结构化状态台账。
2. 先用 `edit/read {experiment_id:"business:<id>",path}` 读取完整正文与摘要，再以同一目标通过 `edit/preview`、`edit/apply` 保存。新文件先确认不存在，expected_sha256 为 null；固定 tag/commit 只读。
3. 回读实际位置、正文与引用。可以使用 adopt、continue、reject 或 inconclusive 表达基于证据的判断；这些是结论，不代表平台状态、Git 合并、实例切换或发布。
4. 摘要冲突先重读，未知写入先查询实际文件，不重复保存。历史 Run、原始输入和冻结事实不因本轮总结改写。
